# 🎮 Rock Paper Scissors – JavaScript Project ✨

Rock Paper Scissors is a browser-based interactive game built using HTML, CSS, and Vanilla JavaScript.  
This project demonstrates DOM manipulation, event handling, conditional game logic, score tracking, and dynamic UI updates.

---

## 🚀 Features

🔹 User vs Computer gameplay  
🔹 Random computer choice generation  
🔹 Real-time score tracking  
🔹 Win / Lose / Draw detection  
🔹 Dynamic result messages  
🔹 Interactive UI with hover effects  
🔹 Responsive and clean design  

---

## 🖥️ Tech Stack

Frontend  
🔹 HTML5  
🔹 CSS3  
🔹 Vanilla JavaScript
